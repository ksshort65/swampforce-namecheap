# Swamp Force — Namecheap upload

1. Download **swampforce.zip** (the file in this repo, not GitHub’s “Code → Download ZIP”).
2. Namecheap File Manager → **public_html**.
3. Upload swampforce.zip → Extract.
4. **index.html must sit inside public_html**, not in a subfolder.
5. Do not delete Proton mail DNS rows.

This zip is the journal (scorecard, GAO tile, essays). Shop is coming soon.
